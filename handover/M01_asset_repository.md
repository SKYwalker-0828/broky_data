# M01 原始资产仓库交接

**状态：** 已实现本地文件参考适配器并通过针对性单元测试；不构成生产后端选型。对象存储、部署、权限和数据治理仍待定。

## 模块职责

保存真实采集、授权取得及合成流程产生的原始图像、可选 3D 和其他大体量二进制资产，并使记录能够通过稳定引用回到准确内容。资产字节与业务元数据分开管理，禁止覆盖原件来保存处理结果。

## 项目/数据库/许可证

- 当前实现：`src/broky_data/asset_store.py` 的 `LocalAssetStore`，将文件按 SHA-256 内容引用写入调用者指定的本地目录；相同内容去重，不覆盖已有对象。
- API：`AssetStore` 定义可替换字节存储协议；`LocalAssetStore` 的 `put_bytes` / `put_stream` 写入并返回 `AssetReceipt`；`open`、`exists`、`verify` 按 `AssetRef` 读取、检查和重算摘要。大文件可用流式写入，过程以分块处理。
- 对象路径为适配器内部细节。发布通过同一文件系统的硬链接实现原子且不可覆盖写入；目标文件系统须支持同卷硬链接，否则写入报错，不回退到可能覆盖或暴露半成品的写法。
- `AssetRef` 与 `AssetReceipt` 是 M01 适配器类型，不是已批准的 RelicWeave `Asset` canonical schema；没有生成业务 manifest，也不保存来源、授权、类型、派生关系或 Truth 标记。
- 本地文件实现仅为原型；生产文件/对象产品、运行环境、容量和访问控制仍**待选**。

## 当前实现行为与限制

1. 调用方显式提供受控根目录；存储模块不读取任意业务路径作为对象 ID，也不暴露删除接口。
2. 写入时分块计算 SHA-256，先落入临时文件并同步，再原子发布；已存在对象需通过摘要校验，不通过时拒绝写入且不覆盖损坏内容。
3. `verify` 重读对象并重算摘要。SHA-256 用于内容完整性和去重，不证明来源真实性、许可状态或考古/物理有效性。
4. 原始输入和衍生件仍需由上层契约分别登记并追踪派生关系；本模块不定义 manifest 字段。
5. 访问授权与隔离必须由后续权限模块或受控后端实现；本地原型不提供 ACL，不能据此开放私有资产或 Truth/GT。

## 输入与输出

- 输入：原始观察、授权文件、A12/PG-Frag 可交付的资产包及其来源引用；PG-Frag 参数化输入来源仍待项目确认。VesselForge 不作为现行来源。
- 输出：适配器 SHA-256 引用与写入字节数；不生成 manifest，也不自动防止上层把引用交给未授权调用方。

## 许可证与数据权利

本实现仅使用 Python 标准库，没有新增第三方运行时依赖或复制第三方代码；`broky_data` 自身许可证未决定。资产授权是独立于软件许可证的事项：每个来源需记录可用于保存、处理、训练、内部展示、出版、公开下载的范围；缺失许可时不得推定可用。

## 交接验收

- 相同字节返回相同引用并复用存储；SHA-256 可复算，篡改和缺失引用可发现。
- 不存在删除 API；已有引用对象不会被覆盖，损坏对象不会被新写入静默修复。
- 失败流不会发布部分对象；非法引用和符号链接存储目录被拒绝。
- 运行 `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest discover -s tests -v` 验证本适配器。
- 访问控制、备份/恢复、加密、规模和授权验证不属于本次原型通过项。
