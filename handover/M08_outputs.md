# M08 标本卡、图版与报告输出交接

**状态：** 本地内部 HTML 标本卡与概览报告已实现；WeasyPrint、Scribus 均未集成。正式模板、图版流程和对外发布能力未实现。

## 当前测试期实现

- `OutputService` 从授权可读的原型记录生成内部 HTML 标本卡和统计概览，采用本地模板、转义字段、原子写入和内容 SHA-256 标识；不得将测试模板当作正式标本卡或报告模板。
- 输出包含测试期说明，不生成 PDF，不执行桌面排版；未提供的考古字段不推断填充。字体、图片出版权、模板签收及视觉验收尚未完成。
- 当前无 WeasyPrint/Scribus 运行依赖；以下候选许可与排版方案仅适用于未来实际集成或分发时。

## 模块职责

将已经审核、授权并可追溯的数据整理为标本卡、图版和报告文件。输出内容需可回查其数据快照、审核状态、所用模板和生成工具，不自行推断缺失考古信息。

## 项目/数据库/许可证

- **WeasyPrint：** HTML/CSS 到 PDF 的模板生成候选，上游 [`LICENSE`](https://github.com/Kozea/WeasyPrint/blob/main/LICENSE) 为 BSD-3-Clause。
- **Scribus：** 独立桌面排版/人工图版精修工具，主程序 [`COPYING`](https://github.com/scribusproject/scribus/blob/master/COPYING) 为 `GPL version 2 or later`。上游说明部分代码另为 LGPL、BSD、MIT、双许可或公有领域，文档/词典/色彩配置/模板等资源可能有独立条款。它不嵌入、链接或打包为 Arches/`broky_data` 运行时依赖。
- 模板数据源、字段/版式和存储数据库均未定。生成物不是关系主记录。

## 正式接入前的目标实现

1. 先由文保/考古业务负责人签收标本卡、图版和报告的字段、单位、图片分辨率、比例尺、署名、隐私与版式规范。
2. WeasyPrint 可用于结构稳定的 HTML/CSS 模板化 PDF；输入仅来自获准的关系/统计/资产引用。渲染前校验缺失字段并输出错误，不填造内容。
3. Scribus 作为独立人工精修工具使用：M08 输出经审核的数据/素材文件，交由桌面用户在 Scribus 中排版，再将成果件送回验收。交接格式和步骤由原型确定；项目不嵌入 SDK、复制 Scribus 代码或把其组件塞入任何服务镜像/安装包。
4. 输出文件另生成 manifest/hash，注明数据快照、模板版本、生成工具版本、人工复核状态；具体元数据格式待确认。
5. PDF/版面预览须做页面尺寸、中文字体、图像链接、页码、图注和比例尺检查；模板/字体的许可独立登记。

## 许可证风险

Arches 与 Scribus 按本设计独立部署并通过文件交接，不据此作许可证兼容/冲突结论。若未来改成同一发行物、容器或代码集成，应按实际版本、代码、资源和发布形式重新审查。WeasyPrint BSD-3-Clause 同样需保留相关声明，并核查传递依赖/字体/模板。

## 交接验收

- 所有输出内容来自可追溯、获准的数据记录；缺值显示为待核或按业务规则处理，不合成虚构文案。
- 有模板、输入快照和工具版本记录，输出 hash 可验证。
- 通过视觉 QA：字体、图片、色彩/尺寸、页码、图例和中文排版无截断重叠。
- 人工修改稿与自动生成初稿可区分；署名、引用和审核信息完整。
- 发布包中的代码、字体、模板、图像和色彩配置均完成许可证/授权核验。
