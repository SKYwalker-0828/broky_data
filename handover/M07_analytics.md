# M07 分类统计与看板交接

**状态：** SQLite 用途级计数与结果汇总已实现；Parquet、DuckDB、Superset 均未集成。统计口径仍为测试期定义。

## 当前测试期实现

- `AnalyticsService` 从本地 SQLite 登记、校验和关系事件中汇总分区、用途、已评估/未评估状态及关系决策计数；调用权限策略区分普通观察数据与 Truth/GT。
- 当前没有看板、置信区间、敏感小样本抑制或经业务签署的统计公式；报告结果不可直接作为正式考古结论或公开统计。
- 当前无 Parquet、DuckDB 或 Superset 依赖。对应许可证说明仅适用于未来采用的具体发行包及其依赖。

## 模块职责

从获准的数据集、关系台账、审核记录和验收收据生成碎片分类统计、关系分布、来源/域覆盖、数据质量和功能表现汇总。分析输出需保留失败样本分母，不能只报已接受子集。

## 项目/数据库/许可证

- **Parquet：** 分析文件格式候选，不是数据库，也没有由格式名确定的运行时软件依赖。
- **DuckDB：** 离线/嵌入式分析引擎候选，上游核心 [`LICENSE`](https://github.com/duckdb/duckdb/blob/main/LICENSE) 为 MIT。
- **Apache Superset：** 看板候选，上游 [`LICENSE.txt`](https://github.com/apache/superset/blob/master/LICENSE.txt) 为 Apache-2.0；上游发行物还列有独立许可子组件/字体。
- 关系事实主库并未选择；分析产物不能回写成为关系权威记录。

## 正式接入前的目标实现

1. 将已冻结快照或经授权的只读导出交给分析 adapter，保留输入版本和过滤条件。
2. 使用 Parquet 作为大批量统计交换/保存格式，DuckDB 做离线查询；如果规模/并发要求不适配，再另行评估替换，不提前添加服务器数据库。
3. 统计类别按项目正式关系语义分列：R0、R1、R2、TINY_CONTACT、UNKNOWN；按片数、来源、域等已确认维度切片。
4. 分别呈现样品、采集、QA、导入、引用闭包、检索、复核等实际失败分母；科学指标的合格 scope 与产品工作流总分母分开展示。
5. Superset 若启用，仅接只读、获准的数据集；账号、行级权限和分享设置须由安全方案确认，不因可视化工具默认设置推定权限有效。
6. 输出表及图表附数据集版本、统计程序版本与生成时间；敏感小样本的显示/抑制规则需项目负责人确认。

## 隐私边界

模型可见、内部管理、授权评测和公开发布统计视图需分权限。未经审查不把 Truth/GT 及可识别来源信息接入看板，也不默认公开关系明细。

## 许可证

DuckDB MIT；Superset Apache-2.0 主许可证。二者的实际发行包、扩展、第三方依赖和字体许可需纳入 SBOM/NOTICE 检查；不得仅用主许可证覆盖所有组件。保留上游声明并遵守 Apache-2.0 的适用通知要求。

## 交接验收

- 同一只读快照及查询版本能复现统计结果。
- 分类和关系统计不合并 TINY/UNKNOWN，不将 R2 传递闭包计作直接邻接。
- 失败分母、排除原因、过滤规则均可追溯。
- Superset 的访客、普通用户、管理员权限分别测试；未配置访问控制时不发布敏感看板。
- 抽样对照原台账确认汇总无遗漏、重复或状态漂移。
