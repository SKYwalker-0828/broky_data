# M06 候选检索派生索引交接

**状态：** SQLite 小规模精确 cosine 原型已实现；向量由调用方提供。FAISS 未集成，生产算法与性能要求未确定。

## 当前测试期实现

- `SearchService` 接受调用方传入的有限数值向量，归一化后按快照/编码器保存新版本索引，并执行精确 cosine 排序；索引记录存于 SQLite。
- 查询只面向 Observation 快照。原型没有模型推理、权重/预处理 hash 绑定、近似索引或大规模性能保证；命中仅供人工参考，不能自动形成关系决定。
- 当前无 FAISS 依赖。FAISS 的 MIT 许可说明仅在未来实际采用相应发行包时适用。

## 模块职责

将经批准的模型/特征输出转换为可重建的检索索引，为候选召回服务。该索引属于派生缓存，不保存或裁决关系真值，也不能取代原始资产、快照或人工核验。

## 项目/数据库/许可证

- **FAISS：** 可选向量近邻索引库，上游 [`LICENSE`](https://github.com/facebookresearch/faiss/blob/main/LICENSE) 为 MIT。
- 向量元数据/实体映射存储：未选；索引 ID 格式和服务接口待定。
- FAISS 索引文件不等于带权限/来源台账的数据库。底层保存位置由 M01/M04 选型后确定。

## 正式接入前的目标实现

1. 仅从批准的 Observation 快照和合格模型版本生成特征；输入名单与快照 manifest 绑定。
2. 每个索引 artifact 随附模型/编码器版本、图库快照、预处理参数、构建软件/版本、索引参数和 hash。字段最终对齐项目 `Model`/`Dataset`/`Validation` 契约。
3. 索引 ID 使用 opaque ID 或仅在受控域可解析的映射，禁止嵌入母体、GT、R2 标签或物理路径。
4. 索引可丢弃并从批准数据重建；更新形成新 artifact，先验证后切换，失败回退而不覆盖旧索引。
5. 如果最终系统不需要向量近邻索引，保持 FAISS 适配器为空，由其他已批准候选召回实现替换。

## 数据安全边界

禁止 Truth/GT、答案配准、候选真值关系、隐藏来源组和确认集标签进入构建数据或向量元数据。离线评测的 Truth join 应由 M04 的隔离流程控制，不从索引服务暴露。

## 许可证

FAISS 上游仓库为 MIT；须保留版权及许可文本。Python/C++ 构建、BLAS/CUDA、wheel 和传递依赖版本不同会影响实际 SBOM，应在锁定具体发行包时复核。MIT 不代表 `broky_data` 自动采用 MIT。

## 交接验收

- 索引可从绑定的输入快照和模型版本重建，hash/参数记录齐全。
- 跨图库或编码器版本不能混用索引；错误版本明确拒绝或要求重建。
- 随机抽查命中项能回到合法观察资产；无法解析或越权的映射不得返回。
- 确认集/Truth-only 样本不会因缓存、临时文件或索引增量写入泄漏。
- 跟不使用 FAISS 的基线比较召回、时延、资源和可重建性后，再决定是否采用。
